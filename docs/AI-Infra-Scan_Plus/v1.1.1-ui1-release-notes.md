# v1.1.1-ui1：恢复基础设施扫描端口选项

日期：2026-10-22。

v1.1.1 维护发布重新编译 Web 时使用了仓库内落后的嵌入静态资源，导致一期的全量 TCP / 固定 AI 端口选项从页面消失。后端默认 `full_tcp` 和 `1–65535` 扫描范围仍在；本补丁修复页面交付回归。

- 从 v1.1.1 标签的前端源码重新构建开源页面并嵌入 Web。
- 校验实际 index 引用的 JS/CSS、两个 radio 模式、请求参数 `params.port_mode`，并核对实际编译二进制包含当前资源。
- 新增发布守卫，避免再次把正确源代码配上旧嵌入页面交付。
- 只更新 Web 镜像为 `ai-infra-guard-webserver:v1.1.1-ui1`；业务目录、规则、端口、环境、Agent 和 Checker 卷沿用。
- 提供适用于已安装 v1.1.1 的预检、维护备份、失败恢复及只回退 Web 配置的补丁回滚。
- 独立规则管理转换器兼容 UI 补丁标签，继续保持原始规则交付与内层资源字节。

操作方法见配套 OPERATIONS.md 或源码 `docs/AI-Infra-Scan_Plus/v1.1.1-ui1-operations.md`。真实验证结论和摘要随最终交付记录提供，不将源码检查等同于页面交互验收。

本补丁不实现持久化扫描续跑，不修改端口扫描策略和数据库结构。旧平台全仓测试存在已记录的基线失效项，定向回归与全仓结果分开记录。

回退边界：支持恢复原 v1.1.1 Web 镜像并保留当前业务数据。UI 补丁会改变 Web 容器 ID，原平台 v1.1.1→v1.1.0 回滚脚本保存的旧 ID 因此失效；不要直接使用原整体回滚入口或手工改写其历史记录。跨回 v1.1.0 需单独适配工具和数据评估。
