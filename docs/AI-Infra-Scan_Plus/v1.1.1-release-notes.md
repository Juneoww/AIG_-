# v1.1.1 扫描停滞维护版

基于已交付 v1.1.0，保留 full_tcp、一期目标输入和旧界面；数据库无迁移。

修复截图后处理无限等待，取消贯穿浏览器、上传、AI、HTTP、端口发现和远程规则初始化。基础检测结果保留，覆盖缺口及逐目标错误写入报告；全部失败不再显示有效的满分报告。用户终止仍保留已完成检测证据，断联已有事件保留并明确失败，不自动续扫。

修复 Web 每事件加载完整历史的性能退化，事件消费与心跳读取分离，限制队列内存；连接替换及任务归属隔离，SSE 慢客户端写入有截止，防止阻塞事件持久化。

端口发现默认4个并发进程，稳定去重、完整TCP端口范围不变。/16 全端口意味着约42.9亿个端口组合，仍需充足时间；本版不以跳过目标换取速度。

配置（Agent 容器环境，Go duration 格式）：AIG_HTTP_TIMEOUT=30s；AIG_SCREENSHOT_TIMEOUT=120s；AIG_UPLOAD_TIMEOUT=120s；AIG_AI_TIMEOUT=300s；AIG_BROWSER_CLEANUP_TIMEOUT=5s；AIG_SERVICE_HTTP_TIMEOUT=120s；AIG_NMAP_WORKERS=4（1-32）；AIG_NMAP_TIMEOUT=0（默认不截断端口发现，可显式设30m，超时会记录未完成）。Web AIG_SSE_WRITE_TIMEOUT=5s。超时不代表无漏洞，也不会删除基础结果；score_valid=false 时不能用评分代表全量覆盖。

交付仅含程序和管理工具，运行镜像每层均无 fingerprints/vuln/vuln_en 规则资源。使用同一共享规则目录，继承历史业务数据和独立复制的 API Checker 卷。

验证与已知限制见 OPERATIONS.md 及源码 docs/AI-Infra-Scan_Plus。本次不包含持久化断点续扫；旧卡死任务须先通过旧页面终止再升级。
